# Security policy

Matriarch runs on your machine and in your AI tools, and reads and writes your
project memory. A problem that could leak memory, code or secrets to someone who
should not see them, or let content in memory or a document take control of a
session, is a security problem.

## Reporting

Use GitHub's private vulnerability reporting: the **Security** tab of this
repository, then **Report a vulnerability**. Please do not open a public issue.

Include what you did, what happened, and what you expected. A maintainer will
answer within a week. Fixes are released as a new version and noted in
`CHANGELOG.md`.

## Supported versions

Only the latest version on `main` receives fixes.
